# Документация на русском

Переведены главы, с которых обычно начинают: быстрый старт, модель угроз, миграция с
проприетарных провайдеров и честный список ограничений. Остальные главы — на английском; ссылки
из переводов ведут на них. Источник истины — английский текст: при расхождении верен он, а
перевод обновляется вслед за ним в том же коммите, что и код (см. [Releases](../operations/releases.md)).
